A modern, vanilla Emacs configuration that prioritizes simplicity, performance, and maintainability.

* Philosophy

** KISS Principle
Keep It Simple, Stupid - follow Occam's Razor for all design decisions.

** Built-in First
- Prefer Emacs built-in packages over external alternatives
- Use ~use-package~ for external packages with ~:ensure t~
- Leverage modern Emacs features (tree-sitter, eglot, etc.)

** Minimal Complexity
- Core settings live directly in ~init.el~
- Modular structure only where it provides clear benefits
- No unnecessary abstractions or complex loading systems
- Readable, self-documenting code

** Performance Oriented
- Optimized startup with ~early-init.el~
- Lazy loading where appropriate
- Minimal package dependencies
- Efficient completion stack (vertico, corfu, marginalia)

* Quick Start

** Installation

1. Clone this repository to =~/.emacs.d=
2. Start Emacs - packages will auto-install
3. Install tree-sitter grammars: =M-x treesit-install-language-grammar=

All sensitive data (passwords, email addresses, feed URLs) is stored in the =private/= directory and git-ignored:

** Required for Full Functionality

# Email (mu4e)

# This config enables built-in *-ts-mode remapping globally.
# When a grammar is missing, Emacs asks before downloading/building it.

# bash c cpp cmake go gomod html javascript json lua markdown markdown-inline
# python rust typescript tsx yaml zig
#+END_SRC

** Optional Language Servers

Eglot is built into Emacs, but the language servers themselves are external programs. Install only the servers for languages you use, and make sure their executables are available in =PATH=.

#+BEGIN_SRC bash
# C/C++
sudo apt install clangd  # or your distro's clang-tools package

# Python
npm install -g pyright  # provides pyright-langserver

# Rust
rustup component add rust-analyzer

# JavaScript/TypeScript
npm install -g typescript-language-server typescript

# Go
go install golang.org/x/tools/gopls@latest

# Bash
npm install -g bash-language-server

# YAML
npm install -g yaml-language-server

# JSON
npm install -g vscode-langservers-extracted

# Markdown
# Install marksman from your OS package manager or upstream release.

# CMake
pipx install cmake-language-server  # or: pip install cmake-language-server

# Zig
# Install zls from your OS package manager or upstream release.
#+END_SRC

The corresponding executables used by this config are =clangd=, =pyright-langserver=, =rust-analyzer=, =typescript-language-server=, =gopls=, =bash-language-server=, =yaml-language-server=, =vscode-json-language-server=, =marksman=, =cmake-language-server=, and =zls=.

* Troubleshooting

** Reload Configuration

#+BEGIN_SRC elisp
M-x eval-expression RET (load-file user-init-file) RET
#+END_SRC

Note: Changes to =early-init.el= require a full Emacs restart.

** Common Issues

- *LSP not starting*: Check if language server is installed and in PATH
- *Packages not installing*: Run =M-x package-refresh-contents=
- *Check errors*: Look in =*Messages*= buffer or start with =emacs --debug-init=
